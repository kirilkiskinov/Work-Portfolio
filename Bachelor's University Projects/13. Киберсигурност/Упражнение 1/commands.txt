dmidecode - DMI table decoder
dmidecode is a free userspace command-line utility for Linux that can parse the SMBIOS data. 
The name dmidecode is derived from Desktop Management Interface, a related standard with which dmidecode originally interfaced. SMBIOS was originally named DMIBIOS. 

dmidecode -t memory
dmidecode -t bios
dmidecode -t system
bios, system, baseboard, chassis, processor, memory, cache, connector, slot
